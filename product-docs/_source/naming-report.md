# 最终命名方案

## 一、主推名:**同崽(Tóngzǎi / Tongzai)**

**一句话定位**:你的同事崽,住在飞书里。

### 为什么是它,而不是评委分最高的"知了"

我没有跟着评委分走,因为这是一道**"高分名几乎全军覆没在商标/域名"**的题。把六个高分名拉到联网核查这一关:

| 高分名 | 致命伤 |
|---|---|
| 知了 | ByteDance 系历史布局 + 极通用词,第9/42类纯文字标"拿到干净注册概率偏低",zhiliao.com 已被占且属活跃商业资产、几乎不可得 |
| 应声 | 通用词显著性弱、同拼音第9类已有在先标,yingsheng.com 裸域几无可能 |
| 墨同 | 已有 MoTong AI Studio 学术实体擦边,"墨X"科技商标极度拥挤,.cn/.us 已占 |
| 晓得 | 与知名在先商标"晓多"(客服/Agent 赛道)高度近似,三个核心域名 WHOIS 实测**全部已注册**,只剩溢价 .ai |
| 拾光 | 撞名密度炸裂(已有同名 AI 相册助手、考勤 AI),"拾光"系商标遍地,裸拼音域名"可得性接近为零" |

辨识度再高,**注不下商标、买不到域名,就是个伪第一名**。一个面向中国企业、要长期建品牌资产的 SaaS,起步就要靠图形组合标硬规避、主域只能用变体后缀——这是先天残疾。

再看崽系:**同崽是唯一一个"无任何已上线同名 AI/SaaS 产品撞名(existingProductCollision: false)"且 risk 标 low 的候选**。对比同族:班崽英文 Banzai 撞 BNZI/Banzai Cloud(硬伤);柚崽有完全同名活跃 App(母婴,第9类大概率已占);豆崽与字节"豆包"一字之差、攀附观感拉满。同崽全避开了。

### 为什么它最适合这个产品

1. **名字即定位**。"同"=同事,一眼锁死"数字同事"主张;"崽"把冷冰冰的 agent 拉成一个有体温、能养、会萌的小家伙。这正是产品要的——不是工具,是"我的人"。
2. **彻底跳出被否决的调性**。Felix 明确枪毙了"同僚/众擎/千机"那种成语腔。同崽是成语→叠系萌名的彻底换轨,和豆包/扣子/妙鸭同一血统,摆一起像真品牌。
3. **吉祥物现成**。"崽"天生可拟人:一只挂着工牌的圆脸小生物,logo / IP / 表情包 / 飞书头像一条龙,视觉资产几乎零门槛。
4. **交互贴脸**。飞书里 `@同崽 帮我订个会`,呼唤即响应,口语化命名让"喊它干活"毫无违和。

### 商标 / 域名状况(据联网核查,落地前需专业复检)

- **撞名**:干净。AI/企业级/飞书生态 agent 赛道**无同名产品**,头对头碰撞为零。
- **商标(风险:中)**:核查标 risky 的真实原因不是同名,而是**"崽"系语义近邻拥挤**——超级崽崽(背靠讯飞)、桌崽等已在 toC 情感陪伴赛道布局,第9/41/42类可能有近似引证。**应对**:① 纯文字"同崽"与图形组合标分开申请;② 坚决避开"崽崽"叠字(降近似度);③ 我们是 **B 端飞书企业 agent**,与那批 toC 二次元陪伴产品**商品/服务类别与受众正好相反**,共存空间实际存在。立项前务必委托代理在第9/35/42类做正式检索。
- **域名(风险:中,需 WHOIS 实查)**:核查给出方向——**优先抢 `tongzai.ai`(该拼音上 .ai 冷门,最可能可得)**;`tongzai.com` 可能被米农持有需评估收购;`tongzai.cn` 中等偏可得。务实首选:`tongzai.ai` 主域 + `gettongzai.com` 兜底。

### 配套 Slogan

> **你的同事崽,住在飞书里。**

备选两条:「人人有个同崽,事儿不用自己扛」/「@一声同崽,活就办了」。

## 三、品牌性格(主推 + 两亚军)

**同崽(主推)**——「黏人的实习同事」。它不端着、不冒充专家,是那个挂着工牌、记得你每件破事、你一喊就颠颠跑过来的小家伙。亲昵但靠谱,萌系外壳下是真能替你把活干完的手脚。性格关键词:贴脸、可靠、有体温。

**多崽(亚军一)**——「人人有份的小分队」。它的人格是复数的、是普惠的——不是给老板的工具,是给公司里每一个普通员工的那一个。气质热闹、平权、有"全员配齐"的爽感,天生适合喊出"人人有 agent"。

**应声(亚军二)**——「最可靠的应答者」。它的性格全在"响应"二字:不废话、不掉线,你开口它就在。沉稳、即时、令行禁止,是偏理性、偏 B 端专业感的那一极,适合强调"对话即办成"的产品叙事。
