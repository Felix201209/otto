## 第 1 步 · 配模型（DeepSeek，写一个文件）

Otto的自定义模型配置是一个**独立文件**，路径固定在：

```
~/.easycode-user/custom-models.json
```

（源码 `customModelsStorage.ts` 写死 `~/.easycode-user/`，用独立文件是为了不和 `settings.json` 抢锁、不被云端更新覆盖。）

新建/编辑它，DeepSeek 完整模板（**可照抄**，这个文件支持 `//` 注释，会被自动剥掉）：

```jsonc
{
  "models": [
    {
      "displayName": "DeepSeek",               // /model 列表里显示的名字，随便起
      "provider": "openai",                    // DeepSeek 是 OpenAI 兼容协议，固定填 openai
      "baseUrl": "https://api.deepseek.com",   // DeepSeek 官方入口（也可写 .../v1，二选一）
      "apiKey": "${DEEPSEEK_API_KEY}",         // ★ 用环境变量占位，绝不把真 key 写死在这
      "modelId": "deepseek-chat",              // DeepSeek 通用对话模型
      "maxTokens": 65536,
      "enabled": true
    }
  ]
}
```

一条命令把目录和文件一起建好（不含任何 key，安全）：

```bash
mkdir -p ~/.easycode-user
cat > ~/.easycode-user/custom-models.json <<'JSON'
{
  "models": [
    {
      "displayName": "DeepSeek",
      "provider": "openai",
      "baseUrl": "https://api.deepseek.com",
      "apiKey": "${DEEPSEEK_API_KEY}",
      "modelId": "deepseek-chat",
      "maxTokens": 65536,
      "enabled": true
    }
  ]
}
JSON
```

> **安全红线（一定守住）：**
> - `apiKey` 字段永远写 `${DEEPSEEK_API_KEY}` 这个占位符，**真 key 只活在环境变量里**，不进这个文件、不进 git、不贴聊天框。
> - 万一手滑把真 key 写进过文件或贴出去过 —— 立刻去 DeepSeek 控制台**吊销重发**，别心存侥幸。

## 第 2 步 · 启动（终端跑三行）

```bash
cd /Users/felix/Desktop/Otto
export DEEPSEEK_API_KEY=sk-你的真实key        # 只在这个终端会话里存活，关窗即消失
npm start
```

启动后，在Otto的交互界面里：

1. 输入 `/model` 回车 → 弹出模型列表。
2. 选你刚配的 **DeepSeek**（就是模板里 `displayName` 那个名字）回车。
3. 随便问一句（比如「你好」），有回复 = 模型通了。

> - 想以后每次自动带上 key、不想每次 export：把 `export DEEPSEEK_API_KEY=...` 写进 `~/.zshrc`，
>   新开终端自动生效。**但 `~/.zshrc` 也别提交进任何 git 仓库。**
> - 没看到 DeepSeek？多半是 `custom-models.json` 格式坏了或没 `enabled: true`。
>   也可以在界面里输 `/add-model` 走交互向导重配一遍（向导会写同一个文件）。

## 第 3 步 · 连飞书（对话里一句话触发扫码）

不用预先配任何飞书凭证。直接在Otto对话里说人话，比如：

```
看我今天的飞书日程
```

它要用飞书时会**自动在对话里弹出一个二维码** —— 这是「档 1 · 扫码自动建应用」流程：
`init → 弹二维码 → 等你扫`。

- 打开**手机飞书 App** → 扫一扫 → 扫这个二维码 → 按提示**授权**。
- 授权成功后，Otto会**用你本人的飞书身份**（不是某个机器人）去读你的日程并回给你。
- 之后日历、文档、表格、云盘、任务等飞书能力都走这一次授权，不用反复扫。

> **务实提醒（别被宣传带跑）：**
> - 这个「扫码自动建应用」走的是飞书**未公开的私有协议**，源码注释自己都写了「飞书可能任意更改/下线」。
>   今天能用，哪天突然弹不出码也别慌——那是协议被动了，不是你配错。届时走「手动填 app_id/secret」的降级档（档 3）。
> - 「懂你岗位/记得你」目前**还很薄**：记忆只是往一个本地 `DEEPV.md` 文件追加文本，没有结构化检索。
>   自己试用时心里有数，这是待建的 P0，不是已经成熟的卖点，别拿它去对外吹。

## 常见问题（FAQ）

**Q：要不要先登录 OrionStar / DeepV 账号？**
不用。配了 `custom-models.json` 走自定义模型（无需登录）模式，全程不碰任何 OrionStar/DeepV 后端，
直连 DeepSeek。这正是「跑国产模型、数据可控」的路子。

**Q：怎么撤销给Otto的飞书授权？**
去**手机/网页飞书** → 头像/设置 → 「授权管理 / 已授权的应用」（飞书叫法可能随版本变）→
找到那个被自动创建的 PersonalAgent 应用 → 移除授权即可。撤销后Otto再要用飞书会重新弹码。
本机侧的飞书凭证缓存在 `~/.easycode-user/` 下，要彻底清掉可一并删除该目录里的飞书相关凭证文件
（删前先看一眼是哪个文件，别误删整个目录里的模型配置）。

**Q：想切回别的模型（比如 GLM 或先前的默认模型）？**
随时输 `/model` 重选即可。想加 GLM 就再编辑 `custom-models.json`，往 `models` 数组里加一条
（`provider: openai`、`baseUrl` 换成智谱的 OpenAI 兼容入口、`modelId` 换成 GLM 的、`apiKey` 同样用
`${ZHIPU_API_KEY}` 这类环境变量占位），存盘后 `/model` 里就会多出来。

**Q：key 写哪最安全？**
只进环境变量（`export` 或 `~/.zshrc`），配置文件里永远是 `${DEEPSEEK_API_KEY}` 占位。
任何时候都别把真 key 贴进聊天框、截图、commit。
