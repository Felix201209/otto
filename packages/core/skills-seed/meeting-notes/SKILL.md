# 会议纪要整理

把一场会的原始记录，变成第二天所有人都能照着执行的纪要。

## 开工先问清
- 会议主题、时间、参会人
- 原始材料形式（录音转写 / 速记 / 要点 / 视频）
- 是否需要匿名或脱敏

## 输出结构
### 一、会议信息
主题 · 时间 · 参会人 · 主持

### 二、关键结论（decisions）
逐条列出"拍板了什么"，一句一条，不含讨论过程。

### 三、待办事项（action items）
表格：事项 | 负责人 | 截止时间 | 优先级
（没明确负责人/时间的，标注"待确认"，绝不臆造。）

### 四、讨论要点
按议题分组，保留有价值的分歧与理由，剔除寒暄与跑题。

### 五、风险 / 遗留问题
未决事项、依赖、下次会议要跟进的点。

## 纪律
- 只记"发生了什么"，不添加没说过的观点
- 分清"结论"与"讨论"——结论是已定，讨论是过程
- 负责人和时间是纪要的命脉，缺失就显式标注"待确认"，不猜
