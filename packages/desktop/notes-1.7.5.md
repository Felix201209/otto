# Otto v1.7.5

这是一次企业预设账号登录与工单路由版本。

## 新增内容

- 新增无需邮箱认证的预设账号登录，由 App 向企业服务器验证账号与密码。
- 新增账号标签体系，可设置普通员工、IT、报修等多个标签。
- IT 报修工单按 `IT` 与 `报修` 标签真正投递到符合条件的启用账号。
- 新增管理员账号入口，可查看、搜索、新增和修改账号、角色、部门、标签及启用状态。
- 新增独立管理员网页：管理员用用户名与强密码登录后，可完整维护预设账号；页面不内置管理令牌。
- 登录令牌由桌面主进程加密保存，不向渲染进程暴露原始令牌。
- Skill 与工具过程统一折叠在“深度思考”中：执行时短暂展开，完成后自动收起，仍可手动查看。
- 专家切换会真正绑定不同专家身份，并在聊天框填入对应的可编辑任务提示；询问身份时会回答当前专家职责。
- 左侧企业组织和对话任务均可展开；任务标题只显示总数，并按今天、昨天、N 天前归类。

## 安装提示

企业登录服务默认连接 `http://59.110.154.44:7777`。macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证；Windows 版本尚未使用商业代码签名。
