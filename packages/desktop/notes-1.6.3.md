# Otto v1.6.3

本次更新修复飞书连接成功后，首条消息仍返回 mock 占位回复的问题。

## 飞书真实 AI 链路

- 每个飞书会话首次收到消息时，会先懒初始化独立的真实 AI runtime，再处理消息。
- 已初始化的飞书会话会复用自己的 runtime，保持不同会话之间的上下文隔离。
- 初始化失败时会返回具体错误，不再用 mock 文案伪装成功。
- 保留断线自动重连、会话同步和流式卡片回推能力。

## 验证

- 新增飞书首条消息回归测试与 server 端到端测试。
- 使用真实本机模型完成隔离探针，确认飞书来源会话返回真实模型内容且不含 mock。

## macOS 首次打开提示

当前安装包未做 Apple 公证。如果系统提示无法验证开发者，请在“系统设置 → 隐私与安全性”中选择“仍要打开”，或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/Otto.app
```
