# Otto v1.6.2

本次更新集中完善企业员工的工作成果沉淀、会议协作与园区通知体验。

## 工作成果与日志

- 工作日志现在记录真实的最终交付成果，不再出现使用后内容空白的问题。
- 新增“总结当下工作”，可将当前会话整理成清晰的工作总结并保存为 Markdown 报告。
- 月历会标记有日志的日期；鼠标悬浮某一天即可按点查看当天全部工作记录。
- 修复本地日期边界与会话隔离，避免日志日期错位或测试数据混入真实记录。

## 企业协作

- 会议结束后可主动询问并生成会议纪要。
- 园区报修支持飞书与短信逐级通知，提升重要事项送达率。

## 界面与稳定性

- 设置与诊断中移除用量统计。
- 暂时隐藏尚未开放的 Skill 与排行榜入口，避免进入空白页面。
- 修复设置悬浮窗口按 Esc 关闭及最新通知相关类型错误。

## macOS 首次打开提示

当前安装包未做 Apple 公证。如果系统提示无法验证开发者，请在“系统设置 → 隐私与安全性”中选择“仍要打开”，或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/Otto.app
```
