# Otto v1.8.6

这是基于队友最新服务端与桌面改动制作的内部测试热修复版本。登录页继续通过单一开关屏蔽，没有删除真实登录、短信注册或邀请码代码。

## 变更内容

- 修复企业工作区运行时代码进入 Electron renderer 后造成的启动黑屏。
- 新增 renderer 构建边界测试，禁止 `otto-server`、`otto-core` 及其子路径以运行时依赖进入沙箱页面；自动 Skill 专家改由 main 进程读取后只传纯数据。
- 将尚未完成跨设备同步与权限校验的职位动态赋权功能继续保持暂缓，避免测试成员获得越权能力或看到无效的调岗、离职入口。
- 保留 v1.8.5 的内部免登录测试身份；测试身份固定为非管理员，不伪造服务端会话，也不会恢复旧 token 或向旧企业租户上报用量与知识。
- 合入队友最新组织架构更新：成员可读取组织视图；邀请链接携带企业服务器地址，冷启动或运行中打开都先切换到对应服务器；退出旧企业后可以接受新的职位邀请。
- 合入浏览器发现本机 Otto 与设置面板接入；尚未具备服务端持久会话的一次性配对入口继续屏蔽，不展示占位成功。
- 修复浏览器预览的 `node:crypto` 打包问题、工作日志日期明细弹层裁切，并保留默认全局自动执行策略；离开“仅当前会话自动”时会在服务端回到手动授权。

## 安全与发布说明

- macOS 安装包仍使用完整 ad-hoc 签名与结构校验，尚未配置 Apple Developer ID 或公证；首次启动可能需要右键选择“打开”。
- Windows 安装包尚未使用商业代码签名。
- 职位动态赋权将在具备服务端白名单、跨设备权威状态和完整端到端测试后重新启用。
- 企业本机 Agent 配对将在具备令牌校验、一次性消费和持久会话后重新开放。
