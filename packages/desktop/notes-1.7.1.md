# Otto v1.7.1

这是 v1.7 的稳定性与体验更新：

- 工作方式改成“日常对话、企业办公、工作代码、工程交付”等通俗名称。
- 模型切换会真正作用到当前对话；修复 Codex OAuth、系统提示词和模型身份识别。
- 个人版补齐 8 位通用办公专家，专家入口、图标和交互文案同步优化。
- 飞书授权二维码可直接显示，并能看到授权链接和工具实时进度。
- 飞书操作不再等待 Otto 桌面确认；修复“空回复”、引用旧消息和回复乱序。

## 安装提示

macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证。首次打开如被系统拦截，请在“系统设置 → 隐私与安全性”中允许打开。Windows 版本尚未使用商业代码签名，SmartScreen 可能提示未知发布者。
