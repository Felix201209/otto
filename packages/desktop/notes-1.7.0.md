# Otto v1.7.0

v1.7.0 引入个人 / 企业双模式：

- 个人版绑定个人 API，只保留基础 Otto、两个会议 Agent、内置 Skill 与自动 Skill 候选。
- 企业版只展示 Otto 托管模型和积分倍率；当前充值与余额为设计预览，不伪造真实支付。
- 企业管理者可构建六部门组织、生成职位邀请，并通过签名链接连接总公司 / 子公司。
- 新增六部门共 24 个基础 Agent，CEO 的通用助手切换为 CEO Agent。
- Skill 专区包含部门 / 公司市场和个人 / Skill 排行榜；企业与好友入口默认折叠。
- 工作日志使用日期日历；点击日期在主区域查看日程，Otto 可通过统一工具自主创建日程。
