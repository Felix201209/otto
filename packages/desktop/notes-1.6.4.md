# Otto v1.6.4

## 新功能

- 已配置模型现在可以编辑全部字段，包括协议、接口地址、API Key、模型 ID、显示名、上下文窗口和启用状态。API Key 留空会保留原密钥；修改模型 ID 或地址时会原子替换，避免残留重复配置。
- 聊天框新增轻量语音输入配件：点击开始录音，再次点击停止；识别结果只填入输入草稿，不会自动发送。支持火山引擎和 OpenAI-compatible ASR，也可选用兼容模型优化转写文本。
- 聊天框右下角新增授权模式选择：手动授权、仅当前会话自动授权、所有会话自动授权。删除、高风险操作和需要用户回答的问题始终要求确认。
- PPT 生成改为完整本地流程：在电脑上渲染并生成 `.pptx`，不再依赖 Otto 云端地址、登录或上传；VS Code 扩展也使用同一套本地生成能力。

## 体验优化

- 授权菜单缩小并放在聊天框角落，三种模式使用不同语义图标，当前选择一目了然。
- 优化专家入口、状态图标、品牌标识与 Otto 小刺猬动效，浅色和深色界面下都更清晰。
- 修复停止生成后工具卡片仍显示处理中、停止按钮无法恢复等状态问题。
- 修复本地用户被企业权限误拦截、组织记忆首次写入目录不存在，以及诊断工具兼容性问题。

## 隐私与兼容性

- 麦克风权限仅在开始录音时请求；语音和模型凭证继续保存在本机安全配置中。
- macOS 版本为 Apple Silicon 构建；当前公开测试渠道仍未做 Apple 公证，首次打开若被系统拦截，请在“系统设置 → 隐私与安全性”中选择仍要打开。
