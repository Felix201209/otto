# Otto v1.8.4

这是 Otto 企业登录、身份控制台和客户端—服务器连接的交付修复版本。

## 变更内容

- 修复企业账号或手机号密码登录、会话恢复和会话过期处理；客户端会先校验企业服务器 API v2 能力，旧服务器不会收到登录密码，并会显示明确升级提示。
- 修复企业邀请码读取与生成：管理员可创建、复制和换新固定 7 天有效的企业引入链接；读取与生成不再互相覆盖，失败后保留输入并可直接重试。
- 企业身份控制台补齐每位成员的 Token 用量、请求次数和最后使用时间，并明确这些数字是客户端回传的内部观察值，不等同于模型供应商账单。
- 登录页防止重复提交、过期短信响应和旧请求覆盖新登录状态；切换登录与注册入口时会清理敏感输入。
- 管理弹窗补齐初始焦点、Tab 焦点限制、Escape 关闭和焦点恢复；保存期间禁止误关，账号列表改为原生表格语义。
- 桌面客户端增强本机与远程企业服务的发现、复用、并发启动、超时和退出收尾，连接失败时返回可执行的错误说明。
- 企业服务器增加真实 API v2 健康与就绪检查、登录限流、企业隔离、原子邀请码、用量配额、安全管理看板和版本/源码提交证明。
- 发布流程固定并核验七个交付资产，将安装包、已推送源码提交、更新清单和 GitHub Release 标签绑定，避免发布错包或旧包。

## 安全说明

管理看板不再接受或记录 URL 查询参数中的平台令牌；敏感页面使用禁止缓存、禁止引用和内容安全策略。生产企业服务必须通过 HTTPS，并报告与发布版本一致的完整源码提交。macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证；Windows 版本尚未使用商业代码签名。
