# Otto v1.7.7

本版本增强联网搜索配置、专家会话体验与 PPT 制作质量。

## 变更内容

- 新增“设置与诊断 → 联网搜索”配置入口，支持 Bing、火山方舟、博查与 Gemini。
- 新增火山方舟 Responses API 搜索接入，可配置 HTTPS API 地址、豆包模型或推理接入点 ID，以及 API Key。
- 搜索 API Key 改为本机 `0600` 独立密钥文件保存；客户端和 Server 回包只显示是否已配置，不回显密钥原文。
- 保存搜索配置后会热更新当前会话，新建会话自动使用最新配置。
- 切换专家并新建会话时，由对应专家先发送身份与能力欢迎语。
- 强化 PPT 创作专家提示词与 `ppt-creator` Skill：固定使用 HTML/CSS/SVG 视觉排版、浏览器逐页渲染与 Node.js/PptxGenJS 组装，禁止使用 Python 生成或排版幻灯片。
- PPT 制作增加故事板、视觉方向、页面类型变化、缩略图总览和逐页检查要求，减少模板感、后台感和重复卡片布局。

## 安装提示

macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证；Windows 版本尚未使用商业代码签名。
