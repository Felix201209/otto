# Otto v1.7.2

这是内部测试模型路由与错误处理修复版本：

- 内部测试阶段所有身份统一使用成员自己绑定的 API，不启用企业中转站、托管模型、积分或充值。
- CEO/企业界面下同样可以添加、编辑和删除个人 API 模型。
- 旧企业会话若保存过 `otto:*` 模型，会自动回退到当前个人模型。
- 未绑定个人 API 时会明确引导进入设置，不再返回 mock 内容。
- 模型请求失败后不再留下空白 Otto 回复，错误会正确收口并显示可读原因。
- 聊天、图片生成和 token 计数统一经过绝对 URL 校验，避免同类故障。
- 补齐 CEO、会议与六个部门共 27 个独立 Imagegen 专家头像。

## 安装提示

macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证。首次打开如被系统拦截，请在“系统设置 → 隐私与安全性”中允许打开。Windows 版本尚未使用商业代码签名，SmartScreen 可能提示未知发布者。
