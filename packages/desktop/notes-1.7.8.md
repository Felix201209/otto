# Otto v1.7.8

这是面向 3 点演示的对话稳定性与 PPT 质量修复版本。

## 变更内容

- 修复模型 API 网络或网关异常时直接显示底层 `fetch failed`、导致用户无法继续对话的问题。
- 当前模型在首个 token 前确认连接失败时，自动切换到另一个已配置且可用的模型接口，并同步更新会话模型选择。
- 备用模型优先选择不同 API 地址，避免同一故障网关上的多个模型重复失败。
- 鉴权、额度、参数等非连接错误仍如实返回，不会被自动切换掩盖。
- 没有可用备用模型时，显示明确的 Base URL、API Key 与网络代理检查提示。
- 重做 PPT 生成规范与本地渲染链路：强化故事板、视觉方向、页面类型变化、真实素材和逐页验收，降低模板感与重复卡片布局。
- 同步增强 CLI、桌面专家与 VS Code 插件中的 PPT 入口和提示词。

## 安装提示

macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证；Windows 版本尚未使用商业代码签名。
