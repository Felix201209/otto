# Otto v1.8.3

这是 Otto v1.8 的企业引入与日常使用体验完善版本。

## 变更内容

- 企业成员引入链接改为可直接分享的公网 HTTPS 地址，网页会展示邀请码并一键打开 Otto；链接固定 5 小时有效，管理员换新后旧链接立即失效。
- 首次注册统一收集企业邀请码、姓名、手机号、短信验证码和登录密码；以后直接用手机号或企业账号加密码登录。
- 登录成功后自动保持会话，重新打开 Otto 无需重复登录；退出登录增加确认，避免误触。
- 企业身份控制台按企业隔离成员，提供岗位与职责标签预设、成员状态和 Token 用量入口。
- 附件改为横向文件卡片，显示文件格式与大小；长文件名自动省略，删除按钮不再覆盖内容。
- PPT 制作与联网搜索成为内置能力，工作日志和设置入口继续简化，更适合普通企业成员使用。

## 安全说明

企业引入页不展示企业内部信息，并启用严格的内容安全策略。生产环境通过 HTTPS 访问企业身份服务。macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证；Windows 版本尚未使用商业代码签名。
