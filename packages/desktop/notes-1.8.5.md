# Otto v1.8.5

这是适配新企业 Microservice 过渡阶段的内部测试版本，并完整合入队友最新的桌面、文档与办公能力更新。

## 变更内容

- 默认屏蔽企业登录页，直接以独立的本地测试成员身份进入完整 Otto 工作区。
- 本地测试身份固定为非管理员，不创建或伪造服务端会话，不显示企业账号、中心邀请码和退出入口，也不会在启动时向旧登录接口发送请求。
- 保留原有账号密码、短信注册和中心邀请码代码；待新 Microservice 提供 HTTPS、版本化健康检查和稳定客户端协议后，可关闭单一测试开关恢复真实认证。
- 合入远端 `internal` 分支最新 27 个提交：PPT 支持原生可编辑文本与表格、智能版式推断和逐页明暗主题；Word、PDF、表格生成引擎升级为内容感知的多版式输出。
- 新增工作日志驱动的主动洞察、会议开始前 10 分钟提醒和右下角 Toast；修复整点调度、多时段触发、跨日去重、旧消息复用和时区显示，并避免把正常结束的会议误报为未完成待办。
- 加固跨盘搜索：绝对工作区外路径必须显式授权，`grep` 与共享路径校验仍能正确接受工作区内以 `..` 开头的合法目录。
- 同时改进跨目录读取提示和外部命令取消反馈。
- 修复自动 Skill 候选回归：模式检测不再把“合格模式数量”误当成“单个模式出现次数”，连续三天重复的工作流会重新进入待确认区。
- 企业工作区新增可靠的系统剪贴板 IPC，复制职位邀请链接不再依赖 renderer 权限。
- 修正企业与身份面板的过度承诺：本机职位邀请默认 24 小时有效，接收方需在 Otto 内手工粘贴，核销状态暂不跨设备同步。
- 更新应用版本、浏览器预览桥接和首启更新说明到 v1.8.5。

## 服务端兼容边界

当前线上新服务为 Otto Enterprise Microservice v4.1，使用 `/auth`、`/invite`、`/accounts`、`/tokens`、`/models` 与 `/api` 路径；它与旧 `/enterprise/*` API v2 的登录字段、注册流程、账号结构和健康检查并不兼容。v1.8.5 通过免登录本地身份解除客户端启动依赖，但不把尚未稳定的新协议包装成已完成的远程认证或模型代理。

## 安全说明

新 Microservice 当前公网入口仅为 HTTP，且尚无版本化健康接口，因此本版不会向它提交密码或会话令牌。内部测试身份没有管理员权限，服务端账号管理和邀请码管理继续留在管理后台。macOS 版本采用本地完整性校验与 ad-hoc 签名，尚未完成 Apple 公证；Windows 版本尚未使用商业代码签名。
