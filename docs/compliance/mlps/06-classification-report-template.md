## 二、系统描述

### 1. 主要业务

根据实际启用模块描述，不得把未上线能力写入正式报告：

- 企业账号、组织、部门、岗位和权限管理；
- Agent 对话、模型调用、文件处理和工具执行；
- 企业知识、个人记忆、工作日志和 Skill；
- 企业私聊、附件、A2A 和可选联邦通信；
- 产业园公告、服务申请、工单、统计和专员分派；
- License、模块授权、健康遥测、积分及计费；
- 飞书、短信和客户选择的模型供应商集成。

| 社会秩序和公共利益 | 待填写 | 待填写 | 无/一般/严重/特别严重 | 待填写 |
| 国家安全 | 待填写 | 待填写 | 无/一般/严重/特别严重 | 待填写 |

### 2. 系统服务安全受到破坏时的影响

分析登录、Agent、企业协作、园区工单、知识、更新、计费和联邦通信中断或被篡改后的服务对象、持续时间、替代方式、经济和社会影响。
