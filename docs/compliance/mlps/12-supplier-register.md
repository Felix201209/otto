# 12 供应商与外部接收方清单

文档状态：`TEMPLATE`

## 1. 准入和持续管理要求

- 明确供应商提供的服务、接收的数据、处理目的、地域、留存、分包和退出方式。
- 核验营业主体、合同、安全条款、隐私条款、服务等级、事件通知和删除证明。
- 涉及个人信息、重要数据、跨境、云基础设施、模型或短信时，由法务、数据保护和安全负责人共同评审。
- API 凭据按供应商分离、最小授权、可轮换并进入密钥管理；禁止共用生产管理员凭据。
- 每年至少复核一次安全状态；重大事件、控制权变更、地域变化或重大漏洞时提前复核。

## 4. 退出检查

停止供应商时，撤销 API Key、OAuth、IAM、Webhook、回调域名和管理员账号；迁移或删除数据；取得删除/返还证明；更新拓扑、数据流、端口、资产、备份和应急联系人；验证旧凭据和旧地址不可继续访问。
