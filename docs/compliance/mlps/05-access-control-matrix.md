## 3. 账号全生命周期

1. 账号创建必须有申请、审批、角色、作用域和到期日。
2. 管理员、数据库、云平台、KMS 和发布账号必须独立，不得共享。
3. 高权限账号启用 MFA；服务账号禁止交互登录并定期轮换凭据。
4. 调岗当日调整权限，离职或合同终止立即禁用账号、会话、密钥和 VPN。
5. 每季度导出实际权限与本矩阵比对，记录多余权限整改。
6. 紧急授权必须限时、双人批准、全程审计并在事件结束后自动撤销。
