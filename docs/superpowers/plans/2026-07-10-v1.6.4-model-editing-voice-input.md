# Otto v1.6.4 Model Editing and Voice Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Otto Desktop v1.6.4 with full-field editing for configured models and a lightweight microphone-to-draft accessory with optional text polishing.

**Architecture:** Extend the existing renderer/WebSocket/server model configuration path with atomic replacement semantics and secret preservation. Add a focused Electron main/preload voice service; renderer records audio and displays state, while main owns credentials and network calls.

**Tech Stack:** TypeScript, React 18, Electron 43, MediaRecorder, Vitest, Node fetch/FormData, electron-builder.
