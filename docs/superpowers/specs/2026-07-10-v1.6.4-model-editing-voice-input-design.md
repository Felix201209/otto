# Otto v1.6.4 模型编辑与语音输入设计

## 目标

v1.6.4 解决两个桌面端缺口：用户可以编辑所有已配置模型的全部可配置字段；聊天输入框增加一个轻量语音配件，把录音转成可审阅的文字，并可选使用大模型润色。

## 范围

### 已配置模型编辑

- 每个已配置模型增加“编辑”操作。
- 可编辑供应商预设、协议、Base URL、API Key、模型 ID、显示名、上下文窗口和启用状态。
- 编辑时不把现有 API Key 返回 renderer；API Key 输入框留空表示保留旧密钥，输入新值才替换。
- 改动会原子替换原模型，即使模型 ID、协议、地址或显示名改变，也不会留下旧条目。
- 如果被编辑模型原本是当前模型，保存后当前模型指向新 ID。

### 轻量语音输入

- Composer 增加麦克风按钮。点击开始录音，再次点击停止。
- 停止后调用配置的 ASR，把转写结果填回输入框，不自动发送。
- 设置中增加折叠的“语音输入”区域：启用、ASR 地址/模型/凭证、润色开关、润色地址/模型/凭证、测试按钮。
- v1.6.4 首期支持 OpenAI-compatible 音频转写接口，并允许填写火山引擎兼容地址；不实现 OpenLess 的全局热键、悬浮胶囊、词汇表、历史和跨应用粘贴。
- 润色使用 OpenAI-compatible Chat Completions。失败时保留原始转写，不阻塞输入。
- 开发验收使用本机 OpenLess 当前的火山识别、DeepSeek 润色和 structured 提示词；凭证仅在本机测试期间读取，不进入仓库、日志或截图。

## 架构

模型编辑沿用 desktop renderer → WebSocket protocol → server 的既有链路。`save_custom_model` 增加可选 `replaceId`，server 根据原 ID 找到完整旧配置，合并留空密钥、原子替换并修正 preferred model。`models_list` 继续只暴露非敏感字段，并补充 modelId/maxTokens/enabled 供编辑表单预填。

语音录制使用 renderer 的 `MediaRecorder`，音频通过受控 preload IPC 送到 Electron main。main 负责读取本机语音配置、调用 ASR 与可选润色接口并返回文本，renderer 永远拿不到已保存的密钥。配置保存在 `~/.otto-user/voice-input.json`；凭证拆到权限为 0600 的 secrets 文件，配置只保存 `{file:...}` 引用。

## 交互

模型行显示“编辑”“删除”。点击编辑后同一设置表单切换为编辑态并完整预填非敏感字段，标题变为“编辑模型”，保存按钮变为“保存修改”，API Key 提示“留空保留当前密钥”。取消编辑恢复新增态。

麦克风按钮有空闲、录音中、处理中三态。录音中按钮高亮并显示停止语义；处理中禁用重复点击；完成后把结果插入当前光标位置。失败以输入框附近的短错误提示呈现，不清空已有草稿。

## 安全与失败处理

- renderer 不读取持久化密钥。
- 网络请求只允许 `https:`，本机开发地址额外允许 loopback `http:`。
- 音频只保存在内存，不默认落盘。
- ASR 失败返回明确错误；润色失败自动回退原始转写。
- 编辑失败不删除旧模型，不改变当前模型。

## 验收标准

- 已配置模型全部字段可进入编辑态并保存；留空 Key 后原模型仍可使用。
- 修改会替换旧条目，模型列表没有重复残留。
- 麦克风录音结束后文字进入草稿且不会自动发送。
- 使用本机 OpenLess 当前配置完成一次真实转写与润色测试。
- macOS 和 Windows 类型检查、单测与打包通过；macOS 真实启动并截图验证。
