## 执行说明

1. 使用 `scripts/test-checklist.sh` 交互式逐项执行测试
2. 测试结果自动记录到 `test-results-{date}.md`
3. 执行完毕后更新本文档摘要表中的统计数据
4. 每项"通过/失败"列填入 ✅ 或 ❌，"实际结果"列记录偏差说明
5. 失败项自动关联回对应 P0 Issue
