# Otto v1.9.2

这是面向企业内测的修复与完整收口版本，包含 v1.9/v1.9.1 已实现但未进入安装包的组织与职位管理改动。

## 本次修复

- 修复客户端退出登录被远端请求阻塞：本机会立即清除并落盘认证状态、回到登录页；中心旧会话在后台撤销，网络不可达也不会把客户端卡在已登录状态。
- 企业管理员后台在成员列表直接提供账号删除入口，二次确认后逻辑删除账号、撤销目标会话并从目录移除；仍禁止删除当前登录账号、跨企业账号或企业最后一名可登录管理员。
- CEO 管理中心新增独立的员工职位安排流程，可更新部门、职位与角色，并立即刷新组织树；员工身份刷新后无需退出重登即可看到新任命。
- `enterprise_collaboration` 新增 `assign_member_position` 动作。客户端会重新核验当前身份为企业管理员、目标是同企业 active 成员，并且只有真实账号更新接口返回成功后才向 Agent 提交结果。

## 完整合入

- 包含 v1.9.1 的企业登录、个人注册与企业升级、组织树、员工直聊、A2A 协作、园区服务、固定企业工作 Agent 与自定义智能体能力。
- 包含此前留在工作树、未进入 v1.9/v1.9.1 安装包的职位管理入口、组织树刷新、当前员工身份更新与设置页直达管理中心改动。
- 企业服务继续使用 schema v4，并保持多租户隔离、账号逻辑删除、会话撤销、邀请码和用量统计兼容。

## 安装说明

- macOS：当前安装包为 ad-hoc 签名，未做 Apple Developer ID 公证；首次启动请在 Finder 中右键 Otto，选择“打开”。
- Windows：当前安装包未做商业代码签名，SmartScreen 可能提示未知发布者，请仅从本 Release 下载并核对校验值。
