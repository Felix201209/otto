# SQLCipher native runtime notices

Otto's platform-specific `better_sqlite3.node` assets are built from:

- [SQLCipher](https://github.com/sqlcipher/sqlcipher), BSD-3-Clause, maintained by Zetetic LLC.
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3), MIT.
- [OpenSSL](https://github.com/openssl/openssl), Apache-2.0.

Release assets must be built from pinned sources, pass the correct-key,
wrong-key, encrypted-header and `cipher_integrity_check` tests, and include a
SHA-256 manifest generated by `scripts/finalize-sqlcipher-native-asset.mjs`.

The open-source SQLCipher code is used directly. Otto must not substitute a
different SQLite encryption extension and label it SQLCipher.
