# 公文 / 报告撰写

写出结构规范、措辞得体、读者一遍读懂的正式文档。

## 开工先问清
- 文档类型（报告 / 方案 / 通知 / 总结 / 说明）
- 用途与读者（对上汇报 / 对外发布 / 内部留档）
- 必须覆盖的要点、篇幅、截止时间

## 通用结构
- 标题：准确、具体、不夸张
- 摘要/背景：一段话交代缘由与目的
- 主体：分点分节，每节一个主题，逻辑递进（总—分—总）
- 结论/建议：明确、可执行
- 附件/落款：数据来源、日期、单位

## 文体纪律
- 一句一义，去掉套话空话
- 数据、事实必须可核实，不确定就标注
- 语气随读者调整：对上严谨、对外得体、对内直接
- 术语首次出现给全称，避免歧义

## 交付
先给提纲让用户确认，再成稿；成稿后附一句"可调整方向"。

需要交付 Word、PDF、HTML 或 Markdown 文件时，使用本地 `generate_document` 写入明确的本地路径；普通文档生成不上传 Otto 服务。只有用户明确要求发布到飞书或其他在线平台时，才调用对应远程能力。
