# 📄 Otto Doc-Writer v6 — 视觉感知排版

> **对标 ppt-creator：AI 定义任务→创造母题→逐节选布局→多态渲染→自检迭代。**
> **你不是模板填充工，你是排版总监。**

---

## 不可妥协

- 交付真实可打开的 `.docx`，不是大纲、不是 Markdown、不是 pandoc 兜底
- 每份文档创造独有视觉母题，禁止"白底黑字塞满字"
- 生成后必须用 Word/WPS 打开检查，不达标则迭代
- 用 `create_docx.py` 生成，走 python-docx 直操

---

## Step 1：先定义传播任务（动手前必做）

一句话锁定：
> 读者读完这份文档后，应该理解/相信/决定/行动什么？

同时确认：文档类型、读者、场合、核心信息、篇幅。

---

## Step 2：创造视觉母题（你设计，引擎执行）

给这份文档的视觉语言命名，选定 3 色：

```yaml
theme: "深空数据"          # 母题名称（必填）
atmosphere: "冷静、专业"    # 气氛
base: "0A1628"            # 基础色
accent: "2D7DD2"          # 强调色
surface: "F0F4F8"         # 表面色
```

**母题速查**（8 选 1，或自创）：

| 母题 | base | accent | surface | 气质 |
|------|------|--------|---------|------|
| 深空数据 | `0A1628` | `2D7DD2` | `F0F4F8` | 科技、冷静 |

## Step 3：逐节设计布局（这里是真正的智能）

用 `##` 标记章节。**每节必须从以下布局中选一个，不允许全文档同一布局**。在节标题后用 `<!-- layout: xxx -->` 声明。

### 五种布局

| 布局指令 | 效果 | 适合 |
|----------|------|------|
| `<!-- layout: narrative -->` | 通栏正文，宽段落 | 背景说明、分析阐述 |
| `<!-- layout: two-column -->` | 左右双栏 | 对比分析、优劣对比 |
| `<!-- layout: data -->` | 通栏 + 突出表格 | 数据报告、资源列表 |
| `<!-- layout: highlight -->` | 引用块 + 要点 | 关键结论、核心观点 |
| `<!-- layout: closing -->` | 通栏 + 右对齐落款 | 结尾、总结、下一步 |

### 示例

```markdown
## 形势研判 <!-- layout: narrative -->

当前新一轮科技革命深入发展...

### 已有基础

- 千兆光纤覆盖全部办公区
- 核心业务系统上线运行，覆盖率85%

### 突出短板

- 数据孤岛严重

## 对比分析 <!-- layout: two-column -->

**传统模式**：纸质流转、邮件审批、周期3-5天

**数字化模式**：线上流转、自动分发、周期4小时

| 指标 | 传统 | 数字化 |
|------|------|--------|
| 审批周期 | 3-5天 | 4小时 |
| 错误率 | 12% | 2% |

## 资源保障 <!-- layout: data -->

| 项目 | 内容 | 预算 | 优先级 |
|------|------|------|--------|
| 基础设施 | 服务器、网络 | 380万 | 高 |
| 软件平台 | 数据中台 | 650万 | 高 |

## 核心结论 <!-- layout: highlight -->

> 数字化转型不是IT项目，而是战略重构。先治理数据，再上平台，最后智能化。

- 2026年底前完成数据中台
- 全员数字素养培训
- CEO 任领导小组组长

## 下一步 <!-- layout: closing -->

建议立即启动。信息化建设办公室
2026年7月18日
```

## Step 4：生成 + 自检 + 迭代

```bash
python scripts/create_docx.py input.md output.docx
```

生成后**必须在 Word 中打开检查**：

- [ ] 封面母题色统一
- [ ] 每节布局正确（双栏有双栏、数据有表格）
- [ ] 无多余空白页
- [ ] 表格可编辑
- [ ] 没有"一眼模板"的感觉

**不达标就调整布局选择或母题配色，重新生成。最多迭代 2 次。**

---

## 引擎

```bash
python scripts/create_docx.py input.md output.docx
```

引擎自动处理：三色→12色派生、多布局渲染、页眉页脚、页码、表格样式。

## 编辑工具

```bash
python scripts/edit_docx.py unpack input.docx work/
python scripts/edit_docx.py pack work/ output.docx
python scripts/comment.py work/ 0 "批注"
python scripts/accept_changes.py input.docx output.docx
```
