# 数据可视化

选对图、讲对故事——图表是为了让人一眼看懂结论。

## 开工先问清
- 数据内容与来源、字段类型（分类 / 时间 / 数值）
- 想传达的核心信息（对比？趋势？占比？分布？关系？）
- 用途：报告静态图 / 网页交互图

## 图表选型（按意图）
- 趋势随时间 → 折线图
- 类别对比 → 柱状 / 条形图
- 占比构成 → 堆叠柱 / 饼图（类别 ≤5 才用饼）
- 分布 → 直方图 / 箱线图
- 相关关系 → 散点图
- 排名 → 排序条形图

## 交付
- 给出图表类型 + 轴 / 系列 / 颜色配置建议
- 一句话点题（图标题就是结论，不是 "XX 图"）
- 解读趋势：指出峰谷、拐点、异常，并给可能原因

## 纪律
- 不误导：y 轴从 0 起（除非明确说明）、比例真实
- 颜色语义化，别用彩虹色堆砌；照顾色盲
- 数据存疑先标注，不美化失真
