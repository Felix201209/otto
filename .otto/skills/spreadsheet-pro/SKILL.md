# 表格数据处理

把一堆数据，变成能回答问题、能决策的表格。

## 开工先问清
- 数据长什么样：字段名、几行示例、来源
- 想得到什么：汇总 / 对比 / 趋势 / 清洗 / 建模
- 目标格式：Excel / CSV / 在线表格

## 常见任务打法
- 清洗：去重、统一格式、处理缺失值（标注而非乱填）、拆合列
- 计算：优先用结构化公式（SUMIFS / XLOOKUP / 透视表）而非硬编码
- 分析：先定问题，再选方法；给出结论 + 支撑数字
- 透视：明确行 / 列 / 值 / 筛选四要素再动手

## 纪律
- 公式给出中文解释，说明每一步在算什么
- 不臆造数据；示例数据显式标注"示例"
- 大数据量优先给"方法 + 公式模板"，让用户在自己数据上套用
- 涉及金额/比例，保留口径说明（含税？环比？）
